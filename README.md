# arduino-battle-car
🚗 Carrinho de combate com Arduino 

📌 Descrição

Projeto de sistema embarcado utilizando Arduino para controle de um carrinho de combate com arduino, com comunicação via Bluetooth e sistema de ataque com servo motor.

⚙️ Tecnologias

C++
Arduino Uno
Bluetooth
Motores DC + Ponte H
Servo motor

🎮 Funcionalidades

Controle remoto via Bluetooth
Movimentação (frente, trás, esquerda, direita)
Sistema de ataque com servo motor
Parada total do sistema

🧠 Conceitos aplicados

Sistemas embarcados
Controle de motores
Comunicação serial
Integração hardware/software
